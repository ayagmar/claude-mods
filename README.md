# ayagmar's Claude Code mods

A [Claude Code](https://claude.com/claude-code) plugin marketplace. Add it once:

```
/plugin marketplace add ayagmar/claude-mods
```

then install what you want from it with `/plugin install <name>@ayagmar`.

| Mod | What it does |
| --- | --- |
| [modmgr](https://github.com/ayagmar/claude-modmgr) | A mod manager: `/mods` shows the mods you have and what each one can do, and finds, installs, switches off, updates or removes them. |

Each entry points at a release tag of its own repository, so installs and updates get releases, never work in
progress.
